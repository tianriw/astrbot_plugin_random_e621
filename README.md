# Random Post IN E621

只是为了我群里的随机图片罢了。
所以 tag 是按照我喜好加排除 ss 内容后的。

需要手动配置 API KEY 和 用户名。
可以设置你自己的 Tag。

已同步 NoneBot 版本的核心能力到 AstrBot 插件：

- `rand621`：随机获取一张帖子
- `fav621 [user_id]`：随机查看某个用户的收藏
- `set_fav621 <post_id>`：将帖子加入当前配置账号的收藏夹

配置项：

- `api_key`：e621 API 密钥
- `user_name`：e621 用户名
- `tags`：查询时使用的标签
- `extra_negative_tags`：额外排除标签，空格分隔
- `proxy_url`：可选 HTTP 代理地址
